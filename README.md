# !mergerncy — 인도 여행 데모

인도 여행지를 고르고 안전한 선택을 체험하는 인터랙티브 데모입니다.
짧은 브랜드 표기는 **!m**입니다.

## 사용

1. 게임형 인트로에서 휴대폰을 꺼냅니다.
2. 오른쪽 스와이프로 다음 도시, 왼쪽 스와이프로 이전 도시를 탐색합니다.
3. **이 도시로 여행하기** 버튼을 눌러 선택한 도시의 서비스를 엽니다.

SPACE는 휴대폰 열기·닫기, ESC는 휴대폰이나 팝업 닫기입니다.
모바일에서는 터치로 도시를 넘길 수 있습니다.

## 배포

GitHub Pages가 `main` 브랜치의 루트에서 정적 파일을 제공합니다.
빌드나 서버 설치가 필요하지 않습니다. `.nojekyll`로 원본 파일을 그대로 게시합니다.

로컬 실행은 프로젝트 폴더에서 `python -m http.server 4173` 실행 후
`http://localhost:4173/`에 접속하면 됩니다.

## 데이터와 자산

- 위험, 경로, 예약, 제보와 미션 점수는 시연 데이터입니다.
- 배경 지도는 OpenStreetMap이며 지도 타일과 웹폰트는 인터넷 연결이 필요합니다.
- GPS와 음성 기능은 브라우저 권한과 지원 여부에 따라 다릅니다.
- 여행지 선택과 직접 작성한 기록은 사용하는 브라우저에 저장됩니다.
- 사진 출처와 라이선스는 [credits.html](credits.html)에 있습니다.
- Leaflet 라이선스는 [vendor/leaflet/LICENSE](vendor/leaflet/LICENSE)에 있습니다.
- 인트로, 인물, 손·휴대폰 연출 및 로고는 사용자가 제공한 자료를 사용합니다.

재배포 시 각 이미지와 라이브러리의 개별 라이선스를 확인하세요.
